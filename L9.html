Theorem — Algebra of Convergent Sequences

The Theorem Statement

THEOREM

Let xₙ → x, yₙ → y, and α ∈ ℝ. Then:

(1) xₙ + yₙ → x + y
(2) αxₙ → αx
(3) xₙyₙ → xy
(4) xₙ/yₙ → x/y  (provided y ≠ 0)

Note for (4): We know that , there exists N ∈ ℕ such that yₙ ≠ 0 for all n ≥ N, so 1/yₙ is eventually well-defined.

Prerequisites

Key Lemmas Used in the Proofs

Each proof strategy builds on these foundational results discussed earlier.

Triangle Inequality

The Core Estimating Tool

Used in every part to split error estimates into manageable pieces involving |xₙ − x| and |yₙ − y| separately.

|a + b| ≤ |a| + |b|
Proposition

Convergent ⟹ Bounded

Every convergent sequence is bounded. Used crucially in Part (3) to bound |xₙ| ≤ C, and in Part (4) to keep |yₙ| away from zero.

xₙ → x ⟹ ∃C>0: |xₙ| ≤ C ∀n
Proposition

Non-zero Limit ⟹ Eventually Non-zero

If yₙ → y ≠ 0, then eventually |yₙ| > |y|/2 This provides the lower bound on |yₙ| needed in the quotient proof.

y ≠ 0 ⟹ ∃N: n≥N ⟹ |yₙ| > |y|/2
Proof Strategies

The Four Proofs in Detail

Each part requires a custom estimation strategy — here is the complete architecture of each argument.

Part (1)
Sum of Sequences
Triangle Inequality
①

Proof of (1) — Addition

Strategy: Split the error using the Triangle Inequality

We need to estimate |xₙ + yₙ − (x + y)|. Rearranging:

|xₙ + yₙ − (x+y)| = |(xₙ−x) + (yₙ−y)| ≤ |xₙ−x| + |yₙ−y| Triangle ineq.

Since xₙ → x and yₙ → y, we can make each term on the right smaller than ε/2 independently. Let ε > 0 be given.

  • Since xₙ → x, ∃ n₁ ∈ ℕ such that n ≥ n₁ ⟹ |xₙ − x| < ε/2
  • Since yₙ → y, ∃ n₂ ∈ ℕ such that n ≥ n₂ ⟹ |yₙ − y| < ε/2
  • Choose N = max{n₁, n₂}. For all n ≥ N both estimates hold simultaneously
  • Therefore: |xₙ + yₙ − (x+y)| ≤ |xₙ−x| + |yₙ−y| < ε/2 + ε/2 = ε □
Key Insight The ε/2 split is the standard device for adding two independent error terms. The N = max{n₁, n₂} ensures both estimates are active at the same time.
Part (2)
Scalar Multiple
Case Split on α
②

Proof of (2) — Scalar Multiple

Strategy: Factor out |α|, handle the α = 0 edge case

We estimate |αxₙ − αx| = |α||xₙ − x|. The natural temptation is to choose N such that |xₙ − x| < ε/|α|. But if α = 0, division is undefined.

⚠ Edge Case: α = 0 If α = 0, then αxₙ = 0 for all n, which is a constant sequence converging to 0 = α·x. The result holds trivially. So we may assume α ≠ 0 for the rest of the proof.

Now assume α ≠ 0. Let ε > 0 be given.

  • Since xₙ → x and α ≠ 0, choose N ∈ ℕ such that n ≥ N ⟹ |xₙ − x| < ε/|α|
  • Then for all n ≥ N:
|αxₙ − αx| = |α| · |xₙ − x| < |α| · ε/|α| = ε   □
Key Insight Always check edge cases before dividing. The α = 0 case is a degenerate but valid scenario that requires separate (trivial) treatment.
Part (3)
Product of Sequences
Add & Subtract Cross Term
③

Proof of (3) — Product

Strategy: Introduce cross term xₙy, use boundedness of {xₙ}

Estimating |xₙyₙ − xy| directly is awkward because both xₙ and yₙ are moving. The trick is to add and subtract the cross term xₙy, linking the error to the individual errors |xₙ − x| and |yₙ − y| separately:

|xₙyₙ − xy| = |xₙyₙ − xₙy + xₙy − xy| add & subtract xₙy
             ≤ |xₙ||yₙ − y| + |y||xₙ − x| triangle ineq.
             ≤ C|yₙ − y| + |y||xₙ − x| |xₙ| ≤ C (bounded)

Since {xₙ} is convergent it is bounded, hence ∃ C > 0 with |xₙ| ≤ C for all n. Let ε > 0 be given.

  • Choose n₁ such that k ≥ n₁ ⟹ |yₖ − y| < ε/(2C)
  • Choose n₂ such that k ≥ n₂ ⟹ |xₖ − x| < ε/(2(|y|+1))
  • Note: we use |y|+1 (not |y|) as the denominator to avoid dividing by zero when y = 0
  • Set N = max{n₁, n₂}. For all k ≥ N:
(2.1) |xₖyₖ − xy| ≤ C|yₖ−y| + |y||xₖ−x|
(2.2)                 ≤ C · ε/(2C) + |y| · ε/(2(|y|+1))
(2.3)                 = ε/2 + |y|ε/(2(|y|+1)) < ε/2 + ε/2 = ε   □
⚠ Why (|y|+1) and not |y|? Using |y|+1 as the denominator ensures we don't divide by zero when y = 0, and it gives the clean bound |y|/(|y|+1) < 1, making the final inequality valid regardless of the value of y.
Key Insight The add-and-subtract trick is a cornerstone of real analysis: introduce the "missing link" xₙy to break a two-variable error into a sum of one-variable errors, each of which you can estimate independently.
Part (4)
Quotient of Sequences
Lower Bound on |yₙ|
④

Proof of (4) — Quotient

Strategy: Prove 1/yₙ → 1/y first; then apply Part (3)

It suffices to show 1/yₙ → 1/y, since then xₙ/yₙ = xₙ · (1/yₙ) → x · (1/y) by Part (3). We estimate:

|1/yₙ − 1/y| = |y − yₙ| / (|yₙ| · |y|) common denominator

To control this, we need a lower bound on |yₙ|. Since yₙ → y ≠ 0, there exists n₁ ∈ ℕ such that:

(2.3) k ≥ n₁  ⟹  |yₖ| > |y|/2

For all k ≥ n₁, using the lower bound |yₖ| > |y|/2:

|1/yₖ − 1/y| = |yₖ − y| / (|yₖ| · |y|) < (2/|y|²) · |yₖ − y| substitute lower bound

Now we can make |yₖ − y| small. Since yₙ → y, choose n₂ ∈ ℕ such that:

(2.5) k ≥ n₂  ⟹  |yₖ − y| < |y|²ε / 2
  • Choose N = max{n₁, n₂}. For all k ≥ N both estimates hold
  • Combine: |1/yₖ − 1/y| < (2/|y|²) · (|y|²ε/2) = ε
  • This proves 1/yₙ → 1/y. Apply Part (3): xₙ/yₙ = xₙ · (1/yₙ) → x · (1/y) = x/y □
Key Insight When you have a denominator converging to something, the danger is it might pass through zero and blow up. The essential lower bound |yₙ| > |y|/2 that prevents this catastrophe.
Master Techniques

The Toolbox Behind All Four Proofs

These four recurring strategies appear throughout real analysis — mastering them here pays dividends everywhere.

Technique 1

The ε/2 — ε/2 Split

When bounding a sum of two terms, allocate ε/2 to each independently. Then N = max{n₁, n₂} ensures both bounds hold simultaneously. Generalizes to ε/k for k terms.

Let ε > 0. Choose n₁: |xₙ−x| < ε/2 Choose n₂: |yₙ−y| < ε/2 N = max{n₁,n₂} ⟹ sum < ε
Technique 2

Add & Subtract a Cross Term

The key maneuver for products. Insert the intermediate term xₙy (or xyₙ) to bridge between the "old" product xy and the "new" product xₙyₙ, splitting the error into parts you can control.

xₙyₙ − xy = (xₙyₙ − xₙy) + (xₙy − xy) = xₙ(yₙ−y) + y(xₙ−x)
Technique 3

Boundedness as a Constant Factor

Convergent sequences are bounded. Replacing the moving term |xₙ| with a fixed constant C converts a two-moving-parts problem into a one-moving-part problem. Use |y|+1 to handle the y=0 edge case cleanly.

|xₙ| ≤ C for all n ⟹ C|yₙ−y| → 0 as yₙ → y (C is a fixed multiplier, not a problem)
Technique 4

Lower Bounding a Denominator

When dealing with reciprocals, you need |yₙ| bounded away from zero. We have |yₙ| > |y|/2 eventually. This gives the upper bound 1/|yₙ| < 2/|y| needed to control the reciprocal error.

|yₙ| > |y|/2 ⟹ 1/|yₙ| < 2/|y| ⟹ |1/yₙ − 1/y| < (2/|y|²)|yₙ−y|
Visual Intuition

Error Estimation Geometry

How each proof "squeezes" the error term to zero.

Part 1 — Addition

Two Arrows, One Target

Split ε equally between the two independent errors; take N large enough for both.

Part 2 — Scalar

Stretching the Error

Multiplying by |α| scales the gap. Choose the original gap smaller than ε/|α| to compensate.

Part 3 — Product

The Cross-Term Bridge

The cross term xₙy creates two one-variable jumps that can each be bounded independently.

Part 4 — Quotient

Keeping the Denominator Safe

Prop. 2.1.22 guarantees yₙ stays in a safe zone bounded away from zero, controlling the reciprocal error.
