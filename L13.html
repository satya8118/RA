Introduction

Subsequences & Convergence

A sequence is an infinite list of real numbers. But what happens when we cherry-pick terms from it, keeping the original order? This is the idea of a subsequence.

Informal Idea

Given a sequence $\,(x_1,\, x_2,\, x_3,\, \ldots)$, a subsequence selects infinitely many terms — say $x_{n_1}, x_{n_2}, x_{n_3}, \ldots$ — where $n_1 < n_2 < n_3 < \cdots$.

Why does this matter? Subsequences are the key tool for:

  • Proving a sequence diverges — by finding two subsequences with different limits.
  • Proving convergence for monotonic sequences — one convergent subsequence is enough.
  • The Bolzano–Weierstrass theorem — every bounded sequence has a convergent subsequence.

Definition

Formal Definition of a Subsequence

Let $(x_n)_{n=1}^{\infty}$ be a sequence of real numbers. Formally, the sequence is a function $x : \mathbb{N} \to \mathbb{R}$.

Definition — Index Set $S$

Let $S = \{n_1, n_2, n_3, \ldots\} \subset \mathbb{N}$ be an infinite subset of $\mathbb{N}$ listed in strictly increasing order: $n_1 < n_2 < n_3 < \cdots$

The subsequence of $(x_n)$ indexed by $S$ is the sequence $(x_{n_k})_{k=1}^{\infty}$.

Equivalent — Composition Form

A strictly increasing function $f : \mathbb{N} \to \mathbb{N}$ gives the same thing. The subsequence is $x \circ f$, i.e.

$$x_{n_k} = (x \circ f)(k), \quad \text{where } n_k = f(k).$$

Strict monotonicity of $f$ ensures we preserve the order of the original sequence.

Key Fact

Because $n_1 < n_2 < \cdots$ are natural numbers, we always have $n_k \ge k$. This simple observation is used repeatedly in proofs.

Observation

For a convergent sequence, every subsequence (no matter which $S$ you choose) must converge to the same limit. We prove this in Theorem 2.

Examples — Divergent Sequences

Using Subsequences to Prove Divergence

Strategy

To prove $(x_n)$ diverges, it suffices to find two subsequences that converge to different limits. This contradicts Theorem 2.

Example 1 — $x_n = (-1)^n$  Diverges

Sequence: $-1,\ 1,\ -1,\ 1,\ -1,\ 1,\ldots$

All terms: −1 +1 −1 +1 −1 +1 …
Odd ($n_k=2k-1$): −1 −1 −1 → −1
Even ($n_k=2k$): +1 +1 +1 → +1

Two subsequence limits: $-1 \ne +1$. Therefore $(-1)^n$ diverges. ✗

Example 2 — $x_n = \sin(n\pi/2)$  Diverges

Sequence: $1,\ 0,\ -1,\ 0,\ 1,\ 0,\ -1,\ 0,\ \ldots$ (period 4)

$n=1,5,9,\ldots$ +1 +1 +1 → +1
$n=3,7,11,\ldots$ −1 −1 −1 → −1

Limits differ ($+1 \ne -1$) ⟹ sequence diverges.

Example 3 — $x_n = n$  Diverges to ∞

Take $S = \{2, 4, 6, \ldots\}$: then $x_{2k} = 2k \to \infty$. Take $S = \{1, 3, 5, \ldots\}$: $x_{2k-1} = 2k-1 \to \infty$. The sequence is unbounded, so it cannot converge to any real number $L$.

Theorem 1

Increasing Sequence + Convergent Subsequence ⟹ Convergence

Theorem 1

Let $(x_n)$ be an increasing sequence of real numbers. If some subsequence $(x_{n_k})$ converges to a limit $L$, then the full sequence $(x_n)$ also converges to $L$.

$$x_1 \le x_2 \le x_3 \le \cdots \quad \text{and} \quad \lim_{k\to\infty} x_{n_k} = L \implies \lim_{n\to\infty} x_n = L.$$

■ Teal bars: convergent subsequence (indices $n_k$)  |  ■ Tan bars: rest of increasing sequence  |  — Gold dashed: limit $L$

Proof

  1. Upper bound: Since $(x_n)$ is increasing and $(x_{n_k}) \to L$, no term can exceed $L$. (If $x_m > L$ for some $m$, then all later terms $\ge x_m > L$, preventing convergence to $L$.) Hence $x_n \le L$ for all $n$.
  2. $\epsilon$-setup: Let $\epsilon > 0$. We must find $N$ so that $n \ge N \Rightarrow |x_n - L| < \epsilon$.
  3. Use the convergent subsequence: Since $x_{n_k} \to L$, $\exists\, K$ with $|x_{n_K} - L| < \epsilon$, i.e. $L - \epsilon < x_{n_K} \le L$.
  4. Squeeze: For any $n \ge n_K$, monotonicity gives $x_{n_K} \le x_n \le L$, so: $L - \epsilon < x_{n_K} \le x_n \le L$, i.e. $|x_n - L| < \epsilon$.
□
Worked Example — Theorem 1 in Action

Define $x_n = 1 - 1/n$ (increasing, bounded above by $1$). Take the subsequence $x_{n_k} = x_{2^k} = 1 - 2^{-k}$.

$$\lim_{k\to\infty} x_{2^k} = \lim_{k\to\infty}\!\left(1 - \tfrac{1}{2^k}\right) = 1.$$

By Theorem 1, $\displaystyle\lim_{n\to\infty} x_n = 1$. ✓

Theorem 2

General Subsequence Criterion (If and Only If)

Theorem 2

A sequence $(x_n)$ converges to $L$ if and only if every subsequence of $(x_n)$ converges to $L$.

$$(x_n) \to L \iff \forall S \subset \mathbb{N} \text{ infinite}, \quad (x_{n_k}) \to L.$$
($\Rightarrow$) Necessity

If $x_n \to L$, show every subsequence $x_{n_k} \to L$.

Proof: Let $\epsilon>0$. Since $x_n \to L$, $\exists N$ s.t. $n\ge N \Rightarrow |x_n - L|<\epsilon$. Now $n_k \ge k$, so choose $K = N$. Then $k \ge K \Rightarrow n_k \ge N$, giving $|x_{n_k}-L|<\epsilon$.

($\Leftarrow$) Sufficiency

If every subsequence converges to $L$, then so does $(x_n)$.

Proof: $(x_n)$ itself is a subsequence of $(x_n)$ (take $n_k = k$). By hypothesis it converges to $L$. ✓

● Rose: Subsequence 1 (approaching $L$ from above)  |  ● Teal: Subsequence 2 (from below) — both converge to $L$.

Corollary — Divergence Test

If we find any subsequence that does not converge to $L$ (or at all), then $(x_n) \not\to L$. In particular, finding two subsequences with different limits guarantees divergence.

Theorem 3 — Peak Lemma

Every Sequence Contains a Monotonic Subsequence

This lemma is the engine behind the Bolzano–Weierstrass theorem.

Definition — Peak

A term $x_m$ is a peak if $x_n \le x_m$ for all $n > m$. (No later term exceeds it.)

Case 1 — Infinitely Many Peaks

List peaks in order: $x_{m_1} \ge x_{m_2} \ge x_{m_3} \ge \cdots$

This is a decreasing (monotone) subsequence. ✓

Case 2 — Finitely Many Peaks

After the last peak index $N$, every term $x_n$ ($n>N$) has some later $x_m > x_n$. We build an increasing subsequence iteratively.

Concrete Example — Peaks in $x_n = \sin(n)/n$

The sequence $\sin(1)/1 \approx 0.84,\ \sin(2)/2 \approx 0.45,\ \sin(3)/3 \approx 0.047,\ldots$ has infinitely many local highs. Collecting these local maxima gives a decreasing subsequence converging to $0$. Collecting local minima gives an increasing subsequence, also converging to $0$. The full sequence also converges to $0$.

Concrete Example — Finite Peaks in $x_n = n/(n+1)$

$x_1 = 1/2 < x_2 = 2/3 < x_3 = 3/4 < \cdots$ — every term is exceeded by the next, so there are zero peaks. Case 2 applies: take $n_k = k$ and get the increasing subsequence which is the sequence itself, converging to $1$.

Why It Matters

Bolzano–Weierstrass: Every bounded sequence has a monotone subsequence (Peak Lemma), and every bounded monotone sequence converges (Monotone Convergence Theorem). Therefore, every bounded sequence has a convergent subsequence.

Conclusion

Since $H_{2^k} > 1 + k/2 \to \infty$, the subsequence $(H_{2^k})$ diverges to $+\infty$. By Theorem 2, the full sequence $(H_n)$ cannot converge. The harmonic series diverges.

Contrast — $\sum 1/n^2$ converges

For $G_n = \sum_{i=1}^n 1/i^2$, the subsequence $G_{2^k}$ satisfies:

$$G_{2^k} < 1 + \sum_{j=1}^{k} 2^j \cdot \frac{1}{(2^{j-1})^2} = 1 + \sum_{j=1}^k \frac{2}{2^j} < 1 + 2 = 3.$$

The subsequence is bounded, which (with monotonicity) implies the series converges. Indeed $\sum 1/n^2 = \pi^2/6 \approx 1.645$.

Summary

Key Ideas at a Glance

Central Theme

Subsequences let us create new convergent or divergent sequences from a given one, and they let us diagnose the behaviour of the original sequence.

Creating Convergence
  • Monotone increasing $(x_n)$ + one convergent subseq ⟹ $(x_n)$ converges.
  • Bolzano–Weierstrass: bounded ⟹ convergent subsequence exists.
  • Cauchy sequences: every subsequence is also Cauchy.
Detecting Divergence
  • Two subsequences → different limits ⟹ diverges.
  • One subsequence → $\pm\infty$ ⟹ diverges.
  • One non-convergent subsequence ⟹ diverges.

Question 5 of 6

Suppose $(x_n)$ is increasing and bounded above. Which of the following is sufficient to conclude $x_n \to L$?

✓ Correct! By Theorem 1: an increasing sequence with a subsequence converging to $L$ must itself converge to $L$. One convergent subsequence is enough when the sequence is monotone.
✗ An upper bound alone doesn't identify the limit — there could be many upper bounds. You need a subsequential limit.
✗ Boundedness by $L+1$ tells you the sequence is bounded, but not that the limit is $L$. Many values smaller than $L+1$ are possible limits.
✗ While Cauchy ⟹ convergent (in $\mathbb{R}$), it does not by itself say the limit equals $L$.
Question 6 of 6

The Peak Lemma guarantees that every sequence contains a monotone subsequence. Which theorem does this most directly help to prove?

✓ Correct! Peak Lemma ⟹ every sequence has a monotone subsequence. If the sequence is bounded, so is the subsequence. Bounded + monotone ⟹ converges (MCT). This gives Bolzano–Weierstrass: every bounded sequence has a convergent subsequence.
✗ The Squeeze Theorem concerns sequences sandwiched between two sequences with the same limit. Not directly related to the Peak Lemma.
✗ The Cauchy Criterion relates to the behaviour of partial sums of a series — a different tool.
✗ The IVT is a continuity theorem for functions, not a result about sequences.
