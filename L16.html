Lecture 18: Continuity via Epsilon-Delta

Real Analysis — Rigorous Metric Proximity, Algebraic Mappings, and Pathological Behaviors

1. The Strict $\epsilon$-$\delta$ Definition of Continuity

In rigorous real analysis, we bypass dynamic limiting metaphors ("approaching a value") to define continuity directly via static metric proximity. Continuity at a given coordinate states that output deviations can be kept inside any arbitrary tolerance window ($\epsilon$) exclusively by restricting the local input domain radius ($\delta$).

Definition (Continuity at a Point): Let $A \subseteq \mathbb{R}$, $f: A \to \mathbb{R}$, and $c \in A$. The function $f$ is continuous at $c$ if for every real tolerance $\epsilon > 0$, there exists a corresponding control radius $\delta > 0$ such that: $$\forall x \in A, \quad |x - c| < \delta \implies |f(x) - f(c)| < \epsilon$$ If $f$ is continuous at every individual point $c \in A$, we say $f$ is continuous on $A$.

1. Motivation — What Should Continuity Mean?

Intuitive Idea
A function $f$ is continuous at a point $c$ if:
  • points near $c$ are mapped to points near $f(c),$
  • the graph has no jump, no hole, no vertical asymptote at $x=c,$
  • you can draw the graph near $c$ without lifting your pen.

The challenge is to make this precise. There are two standard rigorous definitions:

$\varepsilon$-$\delta$ Definition
For every $\varepsilon>0$ there exists $\delta>0$ such that $|x-c|<\delta\Rightarrow|f(x)-f(c)|<\varepsilon.$

Powerful but technical. Requires simultaneous reasoning about two independent small quantities.
Sequential Definition
$f$ is continuous at $c$ if and only if: for every sequence $(x_n)$ with $x_n\to c,$ we have $f(x_n)\to f(c).$

Uses only the already-familiar language of sequences. Often the most natural way to prove or disprove continuity.
Big Picture. The two definitions are equivalent — they define the same class of functions. In this lecture we use the sequential definition as our primary tool, prove its equivalence with $\varepsilon$-$\delta,$ and apply it to a rich collection of examples.

2. Foundational Linear Examples

We verify the core metric structure by analyzing simple linear equations where tracking bounds remains completely independent of localized position coordinates.

Example 1 (Constant Function): Let $f(x) = k$ for a fixed constant $k \in \mathbb{R}$. Prove $f$ is continuous at any $c \in \mathbb{R}$.
Proof: Let $\epsilon > 0$. We must identify a configuration for $\delta > 0$ such that $|x - c| < \delta \implies |f(x) - f(c)| < \epsilon$. Evaluating the absolute target distance calculation: $$|f(x) - f(c)| = |k - k| = 0$$ Since $0 < \epsilon$ holds vacuously true for all positive values of $\epsilon$, we may pick an arbitrary control assignment like **$\delta = 1$**. The structural implication is valid globally across $\mathbb{R}$. $\blacksquare$
Example 2 (Identity Function): Let $f(x) = x$. Prove $f$ is continuous everywhere on $\mathbb{R}$.
Proof: Let $c \in \mathbb{R}$ and let $\epsilon > 0$. We seek a valid metric interval $\delta > 0$ such that: $$|x - c| < \delta \implies |f(x) - f(c)| < \epsilon$$ Substituting our functional parameters directly maps the configuration to: $$|x - c| < \delta \implies |x - c| < \epsilon$$ Setting **$\delta = \epsilon$** trivially satisfies this requirement. $\blacksquare$

3. Non-Linear & Transcendental Continuous Functions

For non-linear mappings, the control radius $\delta$ is constrained both by the selected error tolerance $\epsilon$ and the absolute baseline position coordinate $c$.

Example 3 (The Square Function): Prove $f(x) = x^2$ is continuous at any $c \in \mathbb{R}$.
Proof: Let $\epsilon > 0$. We analyze the target metric expression by factoring terms: $$|f(x) - f(c)| = |x^2 - c^2| = |x - c| \cdot |x + c|$$ To isolate and bound the magnifying factor $|x + c|$, we apply a localized preliminary constraint. Let us choose an initial radius boundary constraint $\delta \le 1$. $$|x - c| < 1 \implies |x| - |c| \le |x - c| < 1 \implies |x| < |c| + 1$$ Applying the triangle inequality on our product factor under this local domain restriction yields: $$|x + c| \le |x| + |c| < (|c| + 1) + |c| = 2|c| + 1$$ Substituting this inequality back into our primary expression generates: $$|x^2 - c^2| < |x - c|(2|c| + 1)$$ To ensure this total product scales strictly underneath the target tolerance threshold $\epsilon$, we choose our control parameter as: $$\delta = \min\left(1, \frac{\epsilon}{2|c| + 1}\right)$$ Thus, whenever $|x - c| < \delta$, both conditions evaluate concurrently, completing our check: $$|x^2 - c^2| < \left(\frac{\epsilon}{2|c| + 1}\right)(2|c| + 1) = \epsilon \quad \blacksquare$$
Example 4 (The Hyperbola on a Positive Domain): Prove $f(x) = \frac{1}{x}$ is continuous at any point $c \in (0, \infty)$.
Proof: Let $c > 0$ and $\epsilon > 0$. We write the metric distance as: $$|f(x) - f(c)| = \left|\frac{1}{x} - \frac{1}{c}\right| = \frac{|x - c|}{cx}$$ To ensure the denominator variable $x$ cannot cause an unbounded expansion as it approaches zero, we construct a safeguard domain barrier by setting $\delta \le \frac{c}{2}$. $$|x - c| < \frac{c}{2} \implies -\frac{c}{2} < x - c < \frac{c}{2} \implies x > \frac{c}{2}$$ Inverting this bound isolates our scaling denominator factor: $\frac{1}{x} < \frac{2}{c}$. Substituting this parameter constraint back yields: $$\frac{|x - c|}{cx} < \frac{|x - c|}{c \cdot \left(\frac{c}{2}\right)} = \frac{2|x - c|}{c^2}$$ To evaluate this total metric distance strictly below $\epsilon$, we define our combined control assignment: $$\delta = \min\left(\frac{c}{2}, \frac{c^2 \epsilon}{2}\right)$$ If $|x - c| < \delta$, then $\frac{|x - c|}{cx} < \frac{2}{c^2} \left(\frac{c^2 \epsilon}{2}\right) = \epsilon$. $\blacksquare$
Example 5 (Concatenated Square Root Function): Prove $f(x) = \sqrt{5 + x^2}$ is continuous at any point $c \in \mathbb{R}$.
Proof: Let $\epsilon > 0$. We transform the absolute metric difference value via conjugate multiplication: $$|f(x) - f(c)| = \left|\sqrt{5 + x^2} - \sqrt{5 + c^2}\right| = \frac{|(5 + x^2) - (5 + c^2)|}{\sqrt{5 + x^2} + \sqrt{5 + c^2}} = \frac{|x - c||x + c|}{\sqrt{5 + x^2} + \sqrt{5 + c^2}}$$ We apply a localized parameter configuration by enforcing $\delta \le 1$, meaning $|x - c| < 1 \implies |x + c| < 2|c| + 1$. Furthermore, the square root denominator can be minorized globally: since $x^2 \ge 0$, it is absolute that $\sqrt{5 + x^2} \ge \sqrt{5}$ and $\sqrt{5 + c^2} \ge \sqrt{5}$. Hence: $$\frac{|x - c||x + c|}{\sqrt{5 + x^2} + \sqrt{5 + c^2}} \le \frac{2|c| + 1}{2\sqrt{5}}|x - c|$$ Therefore, selecting our combined control threshold parameter as: $$\delta = \min\left(1, \frac{2\sqrt{5}\,\epsilon}{2|c| + 1}\right)$$ guarantees that whenever $|x - c| < \delta$, the value stays strictly below $\epsilon$. $\blacksquare$
Example 6 (Trigonometric Sine Wave): Prove $f(x) = \sin x$ is continuous on $\mathbb{R}$.
Proof: Let $c \in \mathbb{R}$ and $\epsilon > 0$. We transform the metric statement using the standard trigonometric product identity: $$|\sin x - \sin c| = \left|2 \sin\left(\frac{x - c}{2}\right) \cos\left(\frac{x + c}{2}\right)\right|$$ Applying the global absolute real inequalities $|\cos \theta| \le 1$ and $|\sin \theta| \le |\theta|$: $$|\sin x - \sin c| \le 2 \left|\frac{x - c}{2}\right| \cdot 1 = |x - c|$$ Hence, selecting **$\delta = \epsilon$** guarantees that $|x - c| < \delta \implies |\sin x - \sin c| < \epsilon$. $\blacksquare$
Example 7 (Natural Exponential Function): Prove $f(x) = e^x$ is continuous at any $c \in \mathbb{R}$.
Proof: Let $\epsilon > 0$. We isolate our coordinate offset factor: $$|e^x - e^c| = e^c|e^{x-c} - 1|$$ Let's impose a local baseline limit by choosing $\delta \le 1$. If $|x - c| < 1$, we can bound the growth of the exponential deviation using the analytic real inequality $|e^u - 1| \le 2|u|$ for all $|u| \le 1$. Substituting $u = x - c$: $$e^c|e^{x-c} - 1| \le 2e^c|x - c|$$ To keep this total expression below our parameter $\epsilon$, we explicitly select: $$\delta = \min\left(1, \frac{\epsilon}{2e^c}\right)$$ This assignment confirms the implication directly. $\blacksquare$

4. Pathological Discontinuous Mappings

To establish that a given function is discontinuous at a coordinate $c$, we formalize the structural negation of our core definition: we identify a specific positive metric distance threshold $\epsilon > 0$ such that *every* positive control candidate radius $\delta > 0$ contains at least one test point $x$ whose output lands outside that target window.

Example A (Discontinuous Only at Zero): Consider the modified indicator step function: $$f(x) = \begin{cases} 1 & \text{if } x > 0 \\ 0 & \text{if } x \le 0 \end{cases}$$ We show $f$ is discontinuous at $c = 0$. Let's choose a fixed tolerance threshold $\epsilon = \frac{1}{2}$.
For any candidate control parameter $\delta > 0$, we can construct a test point $x = \frac{\delta}{2}$. This input point lies directly inside our neighborhood domain since $|x - 0| = \frac{\delta}{2} < \delta$.
However, evaluating its output metric distance configuration shows: $$|f(x) - f(0)| = |1 - 0| = 1 \ge \frac{1}{2}$$ Because this difference exceeds our chosen tolerance $\epsilon$, continuity fails at zero. Conversely, for any alternative coordinate $c \neq 0$, we can configure a localized radius that isolates the function from zero, rendering it locally constant and continuous.
Example B (The Topological Sine Function): Consider the infinite oscillation mapping: $$f(x) = \begin{cases} \sin\left(\frac{1}{x}\right) & \text{if } x \neq 0 \\ 0 & \text{if } x = 0 \end{cases}$$ We prove $f$ is discontinuous at $c = 0$. Select $\epsilon = \frac{1}{2}$. For any choosing radius parameter $\delta > 0$, by the Archimedean property of reals, we can identify a sufficiently large tracking index integer $n \in \mathbb{N}$ such that: $$x_n = \frac{1}{\frac{\pi}{2} + 2n\pi} < \delta$$ This ensures our point satisfies $|x_n - 0| < \delta$. Evaluating its output value yields: $$f(x_n) = \sin\left(\frac{\pi}{2} + 2n\pi\right) = 1 \implies |f(x_n) - f(0)| = |1 - 0| = 1 \ge \frac{1}{2}$$ Hence, the function fails the continuity test at zero due to infinite local oscillations.
Example C (Discontinuous Everywhere — The Dirichlet Function): $$f(x) = \begin{cases} 1 & \text{if } x \in \mathbb{Q} \\ 0 & \text{if } x \notin \mathbb{Q} \end{cases}$$ Let $c \in \mathbb{R}$ be an arbitrary coordinate point, and set $\epsilon = \frac{1}{2}$. For *any* control radius $\delta > 0$, the real interval open segment $(c - \delta, c + \delta)$ contains an infinite mix of both rational and irrational values due to the field density property of real numbers:
  • If $c \in \mathbb{Q}$, then $f(c)=1$. We select an irrational element $x \in (c-\delta, c+\delta)$, yielding $|f(x)-f(c)| = |0-1| = 1 \ge \epsilon$.
  • If $c \notin \mathbb{Q}$, then $f(c)=0$. We select a rational element $x \in (c-\delta, c+\delta)$, yielding $|f(x)-f(c)| = |1-0| = 1 \ge \epsilon$.
Therefore, the Dirichlet function is **completely discontinuous at every single point** across the real line.

5. Preservation Theorems (Algebraic Combinations)

Using only explicit $\epsilon$-$\delta$ structures, we can prove that combining continuous functions preserves their structural continuity properties without using limits.

Theorem 1 (Sum of Continuous Functions): If $f$ and $g$ are both continuous at $c \in \mathbb{R}$, then their combined linear sum function $(f+g)$ is also continuous at $c$.
Proof: Let $\epsilon > 0$.
  • Since $f$ is continuous at $c$, there exists a $\delta_1 > 0$ such that $|x - c| < \delta_1 \implies |f(x) - f(c)| < \frac{\epsilon}{2}$.
  • Since $g$ is continuous at $c$, there exists a $\delta_2 > 0$ such that $|x - c| < \delta_2 \implies |g(x) - g(c)| < \frac{\epsilon}{2}$.
Choose $\delta = \min(\delta_1, \delta_2)$. If $|x - c| < \delta$, we apply the triangle inequality directly: $$|(f+g)(x) - (f+g)(c)| = |(f(x) - f(c)) + (g(x) - g(c))| \le |f(x) - f(c)| + |g(x) - g(c)|$$ Substituting our internal parameter bounds evaluates the metric condition cleanly: $$|(f+g)(x) - (f+g)(c)| < \frac{\epsilon}{2} + \frac{\epsilon}{2} = \epsilon \quad \blacksquare$$
Theorem 2 (Product of Continuous Functions): If $f$ and $g$ are both continuous at $c \in \mathbb{R}$, then their scalar product function $(fg)$ is continuous at $c$.
Proof: Let $\epsilon > 0$. We expand the metric target expression by adding and subtracting a shared terminal factor: $$|(fg)(x) - (fg)(c)| = |f(x)g(x) - f(c)g(c)| = |f(x)g(x) - f(c)g(x) + f(c)g(x) - f(c)g(c)|$$ $$Axiomatically \le |g(x)||f(x) - f(c)| + |f(c)||g(x) - g(c)|$$ First, we establish a localized boundary envelope for $g(x)$. Since $g$ is continuous at $c$, there is a baseline radius $\delta_1 > 0$ such that $|x - c| < \delta_1 \implies |g(x) - g(c)| < 1 \implies |g(x)| < |g(c)| + 1$. Next, we use our scaled components to define our remaining control bounds:
  • Choose $\delta_2 > 0$ such that $|x - c| < \delta_2 \implies |f(x) - f(c)| < \frac{\epsilon}{2(|g(c)| + 1)}$.
  • Choose $\delta_3 > 0$ such that $|x - c| < \delta_3 \implies |g(x) - g(c)| < \frac{\epsilon}{2(|f(c)| + 1)}$.
By setting our comprehensive control configuration parameter to $\delta = \min(\delta_1, \delta_2, \delta_3)$, any input point within range satisfies all inequalities simultaneously: $$|(fg)(x) - (fg)(c)| < (|g(c)| + 1)\left(\frac{\epsilon}{2(|g(c)| + 1)}\right) + |f(c)|\left(\frac{\epsilon}{2(|f(c)| + 1)}\right) < \frac{\epsilon}{2} + \frac{\epsilon}{2} = \epsilon \quad \blacksquare$$
Theorem 3 (Composition of Continuous Functions): If $f$ is continuous at $c$, and $g$ is continuous at the coordinate point $f(c)$, then the composite structure $(g \circ f)$ is continuous at $c$.
Proof: Let $\epsilon > 0$.
Because $g$ is continuous at the coordinate $f(c)$, there exists an interim tolerance radius $\eta > 0$ such that: $$|y - f(c)| < \eta \implies |g(y) - g(f(c))| < \epsilon$$ Next, because $f$ is continuous at $c$, we can treat $\eta$ as our new target output tolerance. This means there exists a control radius $\delta > 0$ such that: $$|x - c| < \delta \implies |f(x) - f(c)| < \eta$$ Combining these two steps: if we choose any input satisfying $|x - c| < \delta$, the output value $y = f(x)$ will satisfy $|f(x) - f(c)| < \eta$. This automatically satisfies the condition for function $g$, yielding: $$|g(f(x)) - g(f(c))| < \epsilon \quad \blacksquare$$

3. Equivalence with the $\varepsilon$-$\delta$ Definition

Theorem — Sequential $\Leftrightarrow$ $\varepsilon$-$\delta$
Let $f:D\to\mathbb{R}$ and $c\in D.$ The following are equivalent:
  1. (Sequential) For every sequence $(x_n)$ in $D$ with $x_n\to c,$ we have $f(x_n)\to f(c).$
  2. ($\varepsilon$-$\delta$) For every $\varepsilon>0$ there exists $\delta>0$ such that $x\in D$ and $|x-c|<\delta$ implies $|f(x)-f(c)|<\varepsilon.$
Proof: $(\varepsilon\text{-}\delta)\Rightarrow(\text{Sequential}).$ Assume the $\varepsilon$-$\delta$ condition. Let $(x_n)$ be any sequence in $D$ with $x_n\to c.$ Let $\varepsilon>0.$

By the $\varepsilon$-$\delta$ condition, there exists $\delta>0$ such that $|x-c|<\delta\Rightarrow|f(x)-f(c)|<\varepsilon.$
Since $x_n\to c,$ there exists $N$ such that $n\ge N\Rightarrow|x_n-c|<\delta.$
Then for all $n\ge N$: $|f(x_n)-f(c)|<\varepsilon.$
Since $\varepsilon>0$ was arbitrary, $f(x_n)\to f(c).$ $\;\square$
Proof: $(\text{Sequential})\Rightarrow(\varepsilon\text{-}\delta)$ — by contrapositive. Suppose the $\varepsilon$-$\delta$ condition fails. Then there exists $\varepsilon_0>0$ such that for every $\delta>0$ there exists $x_\delta\in D$ with $|x_\delta-c|<\delta$ but $|f(x_\delta)-f(c)|\ge\varepsilon_0.$

Taking $\delta=1/n,$ choose $x_n\in D$ with $|x_n-c|<1/n$ and $|f(x_n)-f(c)|\ge\varepsilon_0.$
Then $x_n\to c$ (since $|x_n-c|<1/n\to 0$), but $f(x_n)\not\to f(c).$
So the sequential condition also fails. $\blacksquare$
Why prefer the sequential definition?
  • Proofs of limits of sums, products, composites reduce to limit laws for sequences.
  • Discontinuities are proved by exhibiting a single sequence — no $\varepsilon$-$\delta$ calculation needed.
  • It naturally extends to continuity in metric spaces.

6. Self-Assessment Questions

Test your conceptual control mechanics and analytical skill against these formal verification exercises.

Question 1: Using the strict $\epsilon$-$\delta$ definition, prove that the linear scaling function $f(x) = \frac{1}{3}x$ is continuous at an arbitrary point $c$. What is the explicit choice for $\delta$?

Let's analyze the target metric difference expression for our function: $$|f(x) - f(c)| = \left|\frac{1}{3}x - \frac{1}{3}c\right| = \frac{1}{3}|x - c|$$ We want this expression to be less than our arbitrary tolerance parameter $\epsilon$: $$\frac{1}{3}|x - c| < \epsilon \iff |x - c| < 3\epsilon$$ Therefore, given any $\epsilon > 0$, we define our control assignment explicitly as **$\delta = 3\epsilon$**.
Verification: If $|x - c| < \delta$, then: $$|f(x) - f(c)| = \frac{1}{3}|x - c| < \frac{1}{3}(3\epsilon) = \epsilon \quad \blacksquare$$

Question 2: Consider the function $f(x) = x \sin(1/x)$ for $x \neq 0$, and $f(0) = 0$. Is this function continuous at $c=0$? Prove your conclusion using the $\epsilon$-$\delta$ framework.

Yes, it is continuous at $c=0$. Let $\epsilon > 0$. We evaluate the direct absolute target metric distance expression at the origin: $$|f(x) - f(0)| = \left|x \sin\left(\frac{1}{x}\right) - 0\right| = |x|\left|\sin\left(\frac{1}{x}\right)\right|$$ Since $|\sin \theta| \le 1$ holds globally across all real inputs, we can simplify this expression with an upper bound: $$|x|\left|\sin\left(\frac{1}{x}\right)\right| \le |x| \cdot 1 = |x|$$ We want this expression to remain strictly below our target tolerance parameter $\epsilon$. Thus, by choosing **$\delta = \epsilon$**, the implication satisfies the definition directly: $$|x - 0| < \delta \implies |f(x) - f(0)| \le |x| < \epsilon \quad \blacksquare$$
